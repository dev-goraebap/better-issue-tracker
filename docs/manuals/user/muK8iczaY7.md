# 댓글·첨부·활동으로 함께 일하기

진행 상황과 검토 결과는 해당 이슈의 댓글에 남깁니다. 제목·설명에는 현재 기준을, 댓글에는 변경 이유와 확인 결과를 남기면 읽기 쉽습니다.

## 댓글 남기기

1. 이슈 상세의 **활동** 아래 댓글 입력으로 이동합니다.
2. 현재 상황과 다음 행동을 적습니다. 예: `필수 확인 항목을 정리했습니다. 답변 예시를 검토해 주세요.`
3. 필요하면 **파일 첨부**로 근거 파일을 추가합니다.
4. **보내기**를 누르고 댓글이 활동에 나타나며 입력란이 비워졌는지 확인합니다.

![하위 업무와 검토 요청 댓글이 남은 활동 영역](attachment:HTyH1r1zt8)

댓글은 공백만 보낼 수 없고 본문은 최대 20,000자입니다. 한 번에 연결하는 첨부는 최대 20개이며 파일별 용량·형식 제한도 함께 적용됩니다. 보기 전용은 댓글 작성과 리액션 변경을 할 수 없습니다.

## 파일과 리액션

이미지는 내용에서 확인하고, 다른 파일은 파일 링크로 열거나 다운로드합니다. Word·Excel·PowerPoint·한글 등은 필요한 프로그램으로 열어 확인합니다. 모든 파일에 내장 뷰어가 제공되는 것은 아닙니다. 첨부가 거절되면 [첨부와 저장 문제](mqgVqfia1F.md)를 확인합니다.

리액션 버튼으로 간단한 확인을 표시할 수 있지만, 승인 이유나 실제 작업 결과는 댓글로 적습니다. 활동 기록에서 작성자·변경 시각·속성 변경을 확인하고 자세한 자료는 [문서 연결](mBgnqDN58D.md)로 이어 둡니다.

## 알림과 이어서 작업하기

담당자로 지정되거나 관련 변경이 생겼다면 왼쪽 위 **알림**에서 확인합니다. 알림만으로 업무가 끝난 것은 아니므로 원래 이슈를 열어 상태와 다음 행동을 확인합니다. [알림 사용법](mksVegdF88.md)을 참고합니다.
