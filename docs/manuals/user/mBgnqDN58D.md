# 상위·하위 업무와 관련 자료 연결하기

큰 목표를 작은 작업으로 나누거나 관련 문서를 연결하면 같은 설명을 여러 이슈에 반복해서 쓰지 않아도 됩니다.

## 하위 작업 추가하기

1. 상위가 될 이슈를 엽니다.
2. **하위 작업 추가**를 누르고 제목과 유형을 입력합니다.
3. 상위 업무가 맞는지 확인하고 생성합니다.
4. 상위 상세에 하위 업무 행과 완료 개수가 나타나는지 확인합니다. 하위 제목을 누르면 해당 업무를 엽니다.

![하위 작업과 댓글이 추가된 업무 상세](attachment:HTyH1r1zt8)

상위·하위는 같은 작업 범위 안에서 연결합니다. 유형에 따라 허용되는 상위가 다릅니다. 기본 **스토리**는 에픽 상위가 필요하고, **작업**은 상위 없이 만들거나 허용된 에픽·스토리·작업 아래에 둘 수 있습니다. 관리자가 유형 규칙을 바꾸면 현재 규칙이 우선합니다.

## 관계와 문서 연결하기

상세의 **작업 관계 추가**에서 제공되는 관계를 고르고 관련 업무를 검색합니다. 선행 작업 때문에 막힌 일과 단순 참고 관계를 구분합니다. **문서 연결**은 리소스 문서를 업무에 연결하는 데 사용합니다. 선택 창에서 제목·번호·프로젝트를 확인한 뒤 연결합니다.

리소스 문서 쪽의 **업무 연결**로도 업무를 찾을 수 있습니다. 연결은 내용을 복사하는 동작이 아니므로 원본의 변경은 원본에서 관리합니다. 복사한 URL을 본문에 넣어 안내할 수도 있지만, URL이 접근 권한을 새로 주지는 않습니다.

## 연결되지 않을 때

검색 결과가 없으면 현재 워크스페이스와 프로젝트 범위, 검색어를 확인합니다. 상위 선택이 거절되면 유형의 허용 상위와 필수 여부를 확인합니다. 관계가 순환하도록 연결하거나 다른 범위의 업무를 상위로 지정하지 않습니다.
