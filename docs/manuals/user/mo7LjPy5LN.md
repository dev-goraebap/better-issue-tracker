# BIT의 작업 공간 이해하기

BIT에서는 함께 일하는 사람과 자료를 워크스페이스에 모으고, 그 안에서 프로젝트별로 일을 나눕니다. 먼저 지금 보고 있는 범위를 확인하면 다른 프로젝트에 이슈나 자료를 만드는 실수를 줄일 수 있습니다.

## 워크스페이스와 프로젝트

**워크스페이스**는 구성원과 권한을 관리하는 공간입니다. **프로젝트**는 같은 목표의 이슈와 자료를 모으는 작업 공간입니다. 프로젝트에 들어가면 왼쪽 메뉴와 본문이 해당 프로젝트를 중심으로 바뀝니다.

워크스페이스의 이슈·매뉴얼·리소스에서는 공통 자료와 접근 가능한 프로젝트 자료를 찾을 수 있습니다. 프로젝트 안에서는 그 프로젝트의 자료를 다룹니다. 전체 목록에서 열었다고 자료의 소속이 바뀌지는 않습니다.

## 어디에 무엇을 두나요?

| 메뉴 | 사용할 때 |
| --- | --- |
| 이슈 | 해야 할 일을 만들고 담당자·진행 상태를 관리할 때 |
| 스케줄 | 날짜와 시간이 있는 일정을 확인하고 관리할 때 |
| 매뉴얼 | 반복해서 참고할 사용법과 지침을 섹션·페이지로 정리할 때 |
| 리소스 | 문서와 파일 등 업무에 필요한 자료를 모아 둘 때 |
| 멤버 | 현재 공간의 참여자를 확인하고 허용된 관리 작업을 할 때 |
| 프로젝트 | 워크스페이스의 프로젝트를 찾거나 새로 만들 때 |

메뉴 이름과 순서는 워크스페이스에서 바꿀 수 있으므로 이 안내와 다르게 보일 수 있습니다. 이름을 바꿔도 자료의 소속과 접근 권한이 바뀌지는 않습니다.

## 작업 범위 확인하기

프로젝트 안에서는 사이드바 상단에 프로젝트 이름이 표시됩니다. 예시의 ‘고객 포털’이 보인다면 이슈·스케줄·매뉴얼 등의 메뉴도 고객 포털을 대상으로 합니다.

![고객 포털 프로젝트를 선택한 이슈 화면](attachment:mEhyqWJkeM)

상단의 ‘고객 포털’과 본문 위 경로를 함께 확인합니다. 처음 만든 프로젝트는 이슈가 없으므로 ‘아직 업무가 없습니다’가 표시됩니다.

다른 범위로 이동하려면 사이드바 상단의 프로젝트 이름을 눌러 전환 메뉴를 엽니다. 워크스페이스 이름을 선택하면 워크스페이스 범위로 돌아갑니다.

## 권한 때문에 화면이 다를 수 있어요

같은 워크스페이스에서도 역할에 따라 실행할 수 있는 동작이 다릅니다. 프로젝트 참여 지정은 접근 제한이 아니며, 워크스페이스 조회 권한이 있으면 참여자로 지정되지 않은 프로젝트도 볼 수 있습니다. 만들기·관리 버튼이 보이지 않으면 현재 범위가 맞는지 먼저 확인한 뒤 워크스페이스 관리자에게 권한을 문의합니다.

새 프로젝트가 필요하다면 [프로젝트 만들기](yl8U8QA59h.md)를 따라 진행합니다.
