# 자료가 안 보이거나 저장이 실패할 때

먼저 현재 공간과 권한을 확인하면 불필요하게 자료를 다시 만들지 않아도 됩니다.

## 자주 만나는 상태

| 상태 | 먼저 확인할 것 |
| --- | --- |
| 목록에 자료가 없음 | 워크스페이스·프로젝트 포커스, 검색·필터·뷰, 보관 상태. 조건을 풀고 다시 찾기 |
| 만들기·편집 버튼이 없음 | 보기 전용 또는 사용자 정의 역할인지 확인. 관리자에게 필요한 권한 요청 |
| 보관한 프로젝트 안내 | 자료 조회와 변경의 차이 확인. 변경하려면 프로젝트 보관 해제 요청 |
| 입력값 확인 안내 | 필수 제목, 길이, 날짜 순서, 허용된 상위 업무, 프로젝트 키 등 입력 조건 확인 |
| 다른 사용자가 수정했다는 안내 | 내 초안을 먼저 복사하고 최신 내용을 읽어 합친 뒤 저장 |
| 로그인이 필요하다는 안내 | 세션 만료·비밀번호 변경·전체 로그아웃 여부 확인 후 재로그인 |
| 초대가 열리지 않음 | 원래 링크 전체와 초대 이메일 확인. 만료·폐기·사용됨이면 새 초대 요청 |
| 링크로는 열리지 않음 | 링크 자체는 권한 부여 수단이 아님. 대상 공간에 참여했는지 확인 |

## 첨부할 수 없을 때

파일 이름의 확장자와 실제 형식, 파일별 크기, 한 번에 첨부하는 개수를 확인합니다. 기본 파일별 한도는 20MiB이며 설치 환경에서 달라질 수 있습니다. 한도를 늘려도 허용되지 않은 형식이나 잘못된 파일이 자동으로 허용되지는 않습니다. 필요한 형식이 거절되면 관리자에게 허용 형식과 저장소 설정을 확인해 달라고 요청합니다.

매뉴얼은 파일별 한도 외에 책 전체 이미지 100MiB 한도가 있습니다. 용량이 남아 있어도 파일 하나가 개별 한도를 넘으면 실패합니다. 화면 사진은 원본을 보존하고 글자를 읽기 어려울 정도로 작게 만들지 않습니다. 다운로드 후 여는 Office·한글 파일을 내장 편집이 가능한 문서로 혼동하지 않습니다.

## 저장·복사·PDF 문제

저장 버튼을 눌렀어도 성공 결과를 확인하기 전에는 완료로 생각하지 않습니다. 첨부 업로드가 끝났는지 확인하고 네트워크 오류가 있으면 초안을 복사한 뒤 재시도합니다. 중복 생성이 걱정되면 먼저 목록을 검색합니다.

클립보드 복사 실패는 브라우저 권한, PDF 창이 안 열리는 문제는 팝업·인쇄 지원을 확인합니다. HTML 자체에 고정된 흰 배경은 앱의 다크 모드 오류와 구분합니다. 메일·문서 변환·Git 같은 선택 기능이 꺼진 경우 해당 기능만 사용할 수 없을 수 있습니다.

관리자에게 문의할 때는 현재 공간, 자료 제목·번호, 수행한 단계, 실제 안내 문구와 비밀값이 없는 화면을 전달합니다. 비밀번호·API 키·초대 링크 전체는 공개 댓글이나 일반 문서에 남기지 않습니다.
