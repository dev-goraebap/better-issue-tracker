# 프로필과 화면 모양 바꾸기

**내 설정**은 내 계정과 이 브라우저의 화면 설정입니다. 워크스페이스 관리와 다릅니다.

## 이름과 사진

1. 왼쪽 아래 **내 설정 → 프로필**을 엽니다.
2. 팀원과 활동 기록에 보일 이름을 고치거나 사진 변경 동작을 선택합니다.
3. **저장**한 뒤 표시 이름과 사진을 확인합니다.

![계정 이름·사진·로그인 이메일을 확인하는 프로필](attachment:XrQsYIMs1P)

이름은 필수 최대 64자입니다. 이메일은 로그인에 사용하는 주소이며 변경이 필요하면 인스턴스 관리자에게 요청합니다. 사진에는 업로드 형식·용량 제한이 적용됩니다.

## 테마와 레이아웃

**디스플레이**에서 밝기와 색상 테마, 제공되는 레이아웃을 선택합니다. 시스템 모드를 사용하면 기기의 밝기 설정을 따릅니다. 선택한 테마는 본문·메뉴의 색에 반영되지만 등록된 HTML 페이지의 자체 디자인까지 바꾸지는 않습니다.

![밝기·색상·레이아웃을 고르는 디스플레이 설정](attachment:rLVPLeTkse)

이 화면 설정은 브라우저에 저장됩니다. 다른 브라우저나 기기에서 같은 계정으로 들어가도 같은 모양이 자동 적용된다고 가정하지 않습니다. 사이드바 경계도 끌어 읽기 편한 너비로 조절할 수 있습니다.
