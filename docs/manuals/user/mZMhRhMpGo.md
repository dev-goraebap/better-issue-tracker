# 이슈의 상태·담당자·설명 고치기

목록의 제목을 누르면 상세 패널이 열립니다. **크게 보기**로 넓게 볼 수 있고, 패널 경계를 끌어 너비를 조절할 수 있습니다.

## 상태와 담당자 바꾸기

1. 이슈를 열어 번호와 제목을 확인합니다.
2. 상태를 눌러 이동할 상태를 선택합니다.
3. 담당자·우선순위·유형·라벨·기한도 각각 눌러 고칩니다.
4. 속성은 선택 즉시 반영되므로 표시된 값과 활동 기록을 확인합니다.

프로젝트마다 칸 이름이 다를 수 있습니다. 표시 이름만으로 완료 여부를 단정하지 말고 팀의 [워크플로](mWg7tkeQeh.md)를 따릅니다.

## 제목과 설명 고치기

제목이나 설명을 두 번 누르거나 제공되는 **고치기** 동작으로 편집합니다. 설명에는 `/`로 블록을 넣고 목록·체크리스트·표·코드·이미지 등을 작성합니다. 편집을 마치면 하단 저장 막대의 **저장** 또는 **Ctrl+S**를 사용합니다. **취소**하면 이번 제목·본문 편집을 버립니다.

속성 변경과 제목·설명 저장은 방식이 다릅니다. 상태를 바꿨다고 편집 중인 본문까지 저장된 것으로 생각하지 말고 저장 막대를 확인합니다.

## 반복 업무와 완료 확인

반복 설정이 필요한 업무는 **반복**에서 주기와 간격을 정합니다. 완료 뒤 다음 회차가 생기는지 확인하고, 단발성 업무에는 반복을 설정하지 않습니다. 날짜를 정할 때는 시작일과 기한의 순서를 확인합니다.

수정 충돌이나 권한 변경으로 저장이 실패하면 안내를 읽고 작성 중인 내용을 먼저 복사합니다. 최신 내용을 다시 불러온 뒤 필요한 부분만 합칩니다. 보관된 프로젝트라면 해제 전에는 변경할 수 없습니다.
