# HTML 페이지와 버전 확인하기

HTML로 만든 보고서·화면 자료가 페이지 리소스로 등록되어 있으면 BIT 안에서 열고 버전별로 확인할 수 있습니다. 일반 Markdown 문서와 표시 방식이 다릅니다.

## 페이지 읽기

1. **리소스**에서 해당 페이지를 엽니다.
2. 상단 제목과 선택된 버전을 확인합니다.
3. 가운데 페이지 영역을 읽습니다. 페이지 자체의 배경·글꼴은 등록된 HTML에 따라 달라집니다.
4. 이전 결과와 비교하려면 상단 버전 메뉴에서 다른 버전을 선택합니다.

![HTML 내용과 버전·PDF·댓글 도구를 보여주는 뷰어](attachment:ADYIKtcmUQ)

BIT가 다크 모드여도 HTML 원본에 흰 배경이 고정되어 있으면 페이지는 흰색일 수 있습니다. 전체 앱 테마와 HTML 콘텐츠의 디자인은 별개입니다. 테마에 맞춘 문서가 필요하면 작성자에게 HTML 원본 수정을 요청합니다.

## 의견과 PDF

상단 **댓글**에서 해당 페이지에 대한 의견을 확인하거나 작성합니다. **PDF로 저장**은 BIT의 뷰어 도구입니다. HTML 본문 안에 별도의 저장 버튼을 넣을 필요는 없습니다. 브라우저 인쇄 경로에서 미리보기와 페이지 나눔을 확인합니다.

## 새 페이지나 버전은 어떻게 등록하나요?

현재 화면의 **새 문서**는 Markdown 문서를 만듭니다. HTML 페이지 묶음 등록과 새 버전 추가는 이를 지원하는 API/MCP를 사용하는 작성자·에이전트의 흐름입니다. 리소스 메뉴에 임의의 HTML ZIP 업로드 버튼이 있다고 가정하지 않습니다. 작성자에게 수정본 등록을 요청하고 새 버전이 보이는지 확인합니다.

페이지가 비어 있거나 일부 이미지가 없으면 새로고침·다른 버전을 확인하고 작성자에게 원본 묶음의 파일 경로를 점검해 달라고 요청합니다. 원본 HTML은 BIT 앱과 분리된 영역에서 열리므로 앱 자체 메뉴가 HTML 안에 보이지 않는 것이 정상입니다.
