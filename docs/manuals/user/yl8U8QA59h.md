# 프로젝트 만들기

같은 목표의 이슈와 자료를 한곳에서 관리하려면 프로젝트를 만듭니다. 예를 들어 ‘고객 포털’ 프로젝트에 고객 문의와 계정 기능 개선 작업을 모을 수 있습니다.

**프로젝트 이름**은 사람이 찾는 이름이고, **프로젝트 키**는 업무 번호 앞에 붙는 식별자입니다. 키를 `WEB`으로 정하면 이 프로젝트의 첫 업무 번호는 `WEB-1`입니다.

## 시작하기 전에

- 프로젝트를 만들 워크스페이스에 참여해야 합니다.
- 워크스페이스의 설정을 수정할 권한이 필요합니다. ‘프로젝트 만들기’가 보이지 않으면 관리자에게 권한을 문의합니다.
- 예시에서는 이름을 ‘고객 포털’, 키를 `WEB`으로 사용합니다. 이미 사용한 키라면 다른 키를 정합니다.

## 1. 프로젝트 목록 열기

워크스페이스의 왼쪽 메뉴에서 ‘프로젝트’를 선택합니다. 목록 오른쪽 위의 ‘프로젝트 만들기’를 누릅니다.

![워크스페이스의 프로젝트 메뉴와 오른쪽 위 프로젝트 만들기 버튼](attachment:LPSSQ5Lv57)

왼쪽의 ‘프로젝트’가 선택되고 오른쪽 위에 생성 버튼이 표시되는지 확인합니다. 아직 프로젝트가 없다면 예시처럼 빈 목록이 나타납니다.

## 2. 이름과 키 입력하기

‘새 프로젝트’ 창에서 ‘프로젝트 이름’에 **고객 포털**, 이름 아래의 키 입력칸에 **WEB**을 입력합니다.

![고객 포털이라는 이름과 WEB 키, 설명을 입력한 새 프로젝트 창](attachment:l6kCvNxkpP)

키 오른쪽에 ‘업무 번호가 WEB-1처럼 붙습니다.’가 표시되는지 확인합니다. 설명에는 프로젝트가 하는 일을 적습니다. 예시에서는 ‘고객 문의와 계정 기능 개선을 함께 관리합니다.’를 입력했습니다.

이름에 영문이나 숫자가 있으면 그중 앞의 최대4자로 키가 제안됩니다. **한글 이름만 입력하면 키가 자동으로 채워지지 않으므로 직접 입력합니다.** 키 입력칸의 소문자는 대문자로 바뀝니다. 자동 제안도 사용할 수 있는 키인지 확인해야 합니다.

설명은 생략해도 됩니다. 이름 위의 아이콘을 누르면 아이콘과 색을 고를 수 있고, 바꾸지 않으면 기본 아이콘과 색을 사용합니다.

### 입력 조건

| 항목 | 필수 여부와 기본 동작 | 조건 |
| --- | --- | --- |
| 프로젝트 이름 | 필수, 처음에는 비어 있음 | 앞뒤 공백을 제외하고 최대64자. 공백만으로는 만들 수 없음 |
| 프로젝트 키 | 필수, 이름의 영문·숫자로 제안될 수 있음 | 영문 대문자·숫자2~10자. 공백·한글·기호는 사용할 수 없음. 같은 워크스페이스에서 현재 또는 과거에 쓴 키는 재사용할 수 없음 |
| 설명 | 선택, 처음에는 비어 있음 | 최대20,000자. Markdown으로 작성할 수 있음 |
| 아이콘·색 | 선택, 기본 아이콘·색이 지정됨 | 선택 창에서 원하는 항목을 고름 |

프로젝트 이름을 바꾸는 것과 키를 정하는 것은 다릅니다. 키가 중복됐다면 이름만 바꾸지 말고 **키 입력칸**을 바꿔야 합니다.

## 3. 만들고 결과 확인하기

창 아래의 ‘프로젝트 만들기’를 누릅니다. 키보드로는 `Ctrl + Enter`를 사용할 수도 있습니다.

![생성 후 고객 포털 프로젝트의 이슈 화면](attachment:mEhyqWJkeM)

생성되면 새 프로젝트의 이슈 화면으로 이동합니다. 사이드바 상단과 본문 위 경로에 **고객 포털**이 표시되는지 확인합니다. 처음에는 ‘아직 업무가 없습니다’가 보이며, 이는 프로젝트 생성에 실패했다는 뜻이 아닙니다.

이제 ‘이슈 만들기’로 첫 업무를 등록할 수 있습니다. 전체 프로젝트를 다시 찾으려면 사이드바 상단의 프로젝트 이름을 누르고 전환 메뉴의 ‘프로젝트 목록’을 선택합니다.

## 만들 수 없을 때

이름과 키의 필수·형식 안내는 창에서 확인하고, 키 중복 여부는 만들기를 요청할 때 확인합니다. 입력할 수 있다는 것과 저장할 수 있다는 것은 다릅니다.

| 보이는 안내 또는 상태 | 발생 조건 | 해결 방법 |
| --- | --- | --- |
| ‘프로젝트 이름을 입력해 주세요.’ | 이름이 비어 있거나 공백뿐임 | 이름을 입력하고 다시 만듭니다. |
| ‘프로젝트 키를 입력해 주세요.’ | 키가 비어 있음 | 이름 아래의 키 입력칸에 영문 대문자·숫자2~10자를 입력합니다. |
| ‘키는 영문 대문자·숫자 2~10자로 적어 주세요.’ | 키가 너무 짧거나 길거나 허용하지 않는 문자가 있음 | 한글·공백·기호를 빼고2~10자로 수정합니다. |
| ‘이 워크스페이스에서 이미 쓴 키입니다.’ | 현재 또는 과거에 사용한 키로 생성을 요청함 | 사용하지 않은 다른 키를 입력하고 다시 만듭니다. |
| ‘입력값을 확인해 주세요.’ | 이름 등 입력값이 저장 조건을 벗어남 | 이름이64자 이하인지, 설명이20,000자 이하인지 확인하고 입력 조건에 맞게 줄여 다시 만듭니다. |
| ‘프로젝트 만들기’ 버튼이 보이지 않음 | 현재 범위나 역할에서 생성할 수 없음 | 워크스페이스의 프로젝트 목록인지 확인한 뒤 관리자에게 설정 수정 권한을 문의합니다. |

### 키 형식 고치기

![한 글자 키 W에 대해 2~10자 안내가 표시된 생성 창](attachment:Eilw5metB3)

`W`는 한 글자이므로 만들 수 없습니다. `WEB`처럼2~10자의 키로 바꾼 뒤 다시 ‘프로젝트 만들기’를 누릅니다. 안내가 사라져도 같은 키가 이미 쓰였는지는 제출할 때 확인합니다.

### 중복된 키 바꾸기

![이미 사용한 WEB 키로 요청했을 때 표시되는 안내](attachment:tlBoTUcjG6)

예시에서 이미 만든 고객 포털이 `WEB`을 사용하고 있습니다. 두 번째 프로젝트 이름을 ‘고객 포털 운영’으로 바꿔도 `WEB` 키는 다시 쓸 수 없습니다. **키를 `WEBOPS` 등 사용하지 않은 값으로 바꿔서** 다시 만들면 됩니다.

## 다음에 할 일

새 프로젝트의 이슈 화면에서 첫 업무를 만듭니다. 팀원과 사용 범위를 맞춰야 한다면 프로젝트의 ‘멤버’를 확인하고, 상태 흐름을 바꾸려면 ‘프로젝트 관리’의 ‘워크플로’를 엽니다.
