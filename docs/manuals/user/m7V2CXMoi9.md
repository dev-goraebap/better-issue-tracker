# 초대받고 워크스페이스에 참여하기

초대 링크로 팀의 워크스페이스에 참여합니다. 처음 사용하는 사람은 초대받은 이메일로 계정을 만들고, 이미 계정이 있는 사람은 그 계정으로 로그인해 초대를 수락합니다.

## 초대 내용 확인하기

1. 관리자가 전달한 초대 링크를 엽니다. 링크 전체를 열어야 하며, 초대 확인 전에는 새로고침하지 않는 것이 좋습니다.
2. **초대 확인**을 누릅니다.
3. 워크스페이스 이름, 이메일, 역할, 만료일이 전달받은 내용과 같은지 확인합니다. 다른 팀이나 다른 이메일이라면 진행하지 말고 관리자에게 확인합니다.

![초대를 확인한 뒤 표시되는 워크스페이스와 참여 계정](attachment:gDrei4tWgU)

상단의 이메일이 이번 초대로 참여할 계정입니다. 기존 계정 로그인과 신규 계정 만들기는 서로 다른 절차입니다.

## BIT를 처음 사용하는 경우

1. 화면 아래 **처음 참여하시나요?** 영역으로 이동합니다.
2. 팀에 표시할 이름, 새 비밀번호, 비밀번호 확인을 입력합니다.
3. **초대 계정 만들기**를 누릅니다.
4. 로그인 화면으로 이동하면 초대받은 이메일과 방금 정한 비밀번호로 로그인합니다.
5. 참여한 워크스페이스를 엽니다. 계정 생성과 함께 참여가 처리되므로 같은 초대를 다시 수락할 필요는 없습니다.

![새 계정의 이름과 비밀번호를 입력하는 영역](attachment:PTcx3eKSPc)

| 입력 | 조건 |
| --- | --- |
| 이름 | 필수, 공백만 사용할 수 없으며 최대 64자 |
| 새 비밀번호 | 15~64자이면서 UTF-8 72바이트 이하. 한글 등은 한 글자가 여러 바이트일 수 있음 |
| 비밀번호 확인 | 새 비밀번호와 동일하게 입력 |
| 이메일 | 초대에 지정된 이메일 사용. 다른 이메일로 참여하려면 새 초대를 요청 |

## 이미 계정이 있는 경우

1. **기존 계정으로 참여**에서 초대 이메일의 계정으로 로그인합니다.
2. 표시된 로그인 계정과 초대 이메일이 같은지 확인합니다.
3. **초대 수락**을 누릅니다. 이미 다른 이메일로 로그인했다면 **다른 계정으로 로그인**을 먼저 누릅니다.
4. 초대한 워크스페이스의 이슈 화면으로 이동했는지 확인합니다.

![로그인한 기존 사용자가 초대를 수락하는 화면](attachment:MMdX6egnzj)

초대 화면에 표시된 역할은 영문으로 보일 수 있습니다. `member`는 멤버, `viewer`는 보기 전용입니다. 가능한 작업은 [역할과 권한](mr0ViclaWh.md)에서 확인합니다.

## 참여할 수 없을 때

![사용이 끝난 초대를 다시 확인했을 때의 안내](attachment:JMTFdNhB4z)

| 보이는 상태 | 할 일 |
| --- | --- |
| 초대 링크가 필요하다는 안내 | 관리자에게 받은 원래 링크 전체를 다시 엽니다. 주소 끝의 초대 정보가 빠지지 않았는지 확인합니다. |
| 사용할 수 없는 초대 | 초대가 만료·폐기되었거나 이미 사용되었습니다. 관리자에게 새 초대를 요청합니다. 기본 유효기간은 7일이며 한 번만 사용할 수 있습니다. |
| 다른 이메일로 전환하라는 안내 | 초대받은 이메일로 로그인합니다. 현재 계정으로 수락할 수 없습니다. |
| 비밀번호 확인 불일치 | 두 입력을 동일하게 고칩니다. 가입이 실패한 뒤 비밀번호 입력이 비워졌다면 다시 입력합니다. |
| 이미 계정이 있다는 안내 | 새 계정을 만들지 말고 기존 계정으로 로그인합니다. 비밀번호를 모르면 인스턴스 관리자에게 복구를 요청합니다. |

참여 뒤에는 [작업 공간](mo7LjPy5LN.md)을 확인하고 프로젝트를 선택합니다.
