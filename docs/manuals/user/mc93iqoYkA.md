# 프로젝트 참여 멤버 관리하기

프로젝트 멤버는 해당 프로젝트에 함께 일하는 사람을 정리하는 목록입니다. 워크스페이스에서 이미 참여 중인 사람을 프로젝트에도 지정합니다.

## 참여자 확인과 변경

1. 프로젝트를 연 뒤 **멤버**를 선택합니다.
2. 참여 중인 사람과 역할을 확인합니다.
3. 관리 권한이 있다면 멤버를 추가하거나 행 끝 **더보기 → 참여 프로젝트 관리**를 엽니다.
4. 해당 프로젝트의 참여를 켜거나 끕니다. 변경 뒤 목록에서 결과를 확인합니다.

![프로젝트에 지정된 멤버 목록](attachment:DYHquxVuxD)

목록에 없는 새 사람은 먼저 워크스페이스로 초대해야 합니다. 프로젝트 참여를 추가하면서 새 BIT 계정을 만드는 방식은 아닙니다.

## 제외와 내보내기 구분

**프로젝트에서 제외**는 이 프로젝트의 참여 목록에서 빼는 동작입니다. **워크스페이스에서 내보내기**는 워크스페이스 접근을 없애는 동작이며 다시 참여하려면 새 초대가 필요합니다. 확인 창의 대상을 읽고 선택합니다.

프로젝트 참여 지정은 비공개 접근 제어가 아닙니다. 워크스페이스 조회 권한이 있는 사람은 참여자로 지정되지 않아도 프로젝트를 볼 수 있습니다. 참여 목록과 실제 권한을 구분하려면 [역할과 권한](mr0ViclaWh.md)을 참고합니다.
