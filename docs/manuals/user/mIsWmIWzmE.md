# 멤버 초대·역할 변경·내보내기

워크스페이스의 **멤버**에서 참여자와 초대를 관리합니다. 기본 역할의 관리자·소유자 또는 멤버 관리 권한이 있는 사용자가 수행합니다.

## 새 멤버 초대하기

1. 워크스페이스의 **멤버**를 열고 초대 버튼을 누릅니다.
2. 이메일과 부여할 역할을 확인합니다. 여러 사람은 행을 추가하거나 이메일 목록을 붙여 넣습니다.
3. 초대를 만들고 결과에서 각 링크를 복사해 해당 사람에게 전달합니다.
4. 받은 사람이 참여하면 멤버 목록에서 이름과 역할을 확인합니다.

![여러 이메일과 역할을 입력하는 초대 창](attachment:EE5QSwWJOp)

한 번에 최대 50행을 처리할 수 있습니다. 같은 이메일은 대소문자를 구분하지 않고 중복을 정리하며, 빈 행만으로는 초대할 수 없습니다. 이메일은 화면 입력 기준 최대 254자입니다. 링크는 기본 7일 동안 한 번 사용할 수 있고, 결과 링크는 다시 볼 수 있다고 가정하지 말고 생성 직후 안전하게 전달합니다. 메일이 설정되지 않은 환경에서는 자동 이메일 발송을 기대하지 않습니다.

초대 상태를 확인해 만료·폐기된 초대는 새로 발급합니다. 이미 대기 중인 초대가 있다면 기존 초대 처리 상태를 확인하고 중복 발급하지 않습니다. 받는 사람의 절차는 [초대 수락](m7V2CXMoi9.md)을 전달합니다.

## 역할과 참여 프로젝트 변경

1. 멤버 행 끝 **더보기**를 엽니다.
2. **역할 변경**에서 새 역할을 선택하고 변경합니다. 워크스페이스 전체와 API 키 권한에 적용됩니다.
3. **참여 프로젝트 관리**에서는 프로젝트 참여를 켜거나 끕니다.

![멤버 행의 역할·프로젝트·내보내기 메뉴](attachment:SMT6de3yt5)

자신·소유자 또는 자신이 관리할 수 없는 대상에게는 역할 변경·내보내기가 표시되지 않을 수 있습니다. 관리자는 동급 관리자와 소유자를 일반 멤버처럼 관리하지 않습니다. [권한 비교](mr0ViclaWh.md)를 참고합니다.

## 나가기와 내보내기

**워크스페이스에서 내보내기** 확인 뒤에는 그 사람이 해당 공간에 접근할 수 없습니다. 프로젝트 제외와 구분합니다. 본인의 **워크스페이스에서 나가기**도 다시 참여하려면 초대가 필요합니다. 소유자는 일반 나가기 대신 먼저 소유권 이전 절차를 확인해야 합니다.
