# 첫 이슈 만들기

해야 할 일을 제목과 설명으로 남기고 담당자·상태·기한을 정합니다. 화면 메뉴 이름은 **이슈**, 기본 업무 유형은 **작업**이므로 생성 버튼에는 **작업 만들기**가 표시될 수 있습니다.

## 만들기

1. 왼쪽 **이슈**를 열고 **이슈 만들기**를 누릅니다.
2. 상단의 프로젝트 표시를 확인합니다. 워크스페이스에서 시작했다면 프로젝트를 선택하거나 공통 업무로 둡니다.
3. 제목에 `고객 문의 답변 양식 정리`처럼 해야 할 일을 적습니다.
4. 설명에는 배경, 작업 내용, 완료 기준을 적습니다. 필요하면 파일을 첨부합니다.
5. 유형·상위 업무·상태·우선순위·담당자·라벨·기한을 선택합니다. 표시된 상태가 시작하려는 상태인지 확인합니다.
6. **작업 만들기** 또는 **Ctrl+Enter**로 저장합니다.

![프로젝트와 담당자를 정한 작업 생성 창](attachment:ZL7xXje5rx)

저장 뒤 목록에 제목과 `WEB-8` 같은 번호가 생깁니다. 번호를 열어 입력한 설명과 담당자가 남았는지 확인합니다. **계속 만들기**를 켜면 연속해서 새 업무를 입력할 수 있습니다.

## 입력 조건과 선택 기준

| 항목 | 조건·용도 |
| --- | --- |
| 제목 | 필수, 공백만 입력할 수 없으며 최대 200자 |
| 설명 | 선택, 최대 20,000자. 문단·목록·표·코드 등 Markdown 기반 내용 |
| 프로젝트 | 공통 업무 또는 워크스페이스 안의 프로젝트. 보관된 프로젝트에는 새 업무를 만들 수 없음 |
| 유형·상위 업무 | 유형에 따라 상위 업무가 필수이거나 선택 가능. [업무 구조](mBgnqDN58D.md) 참고 |
| 담당자 | 함께 처리할 사람을 선택, 최대 20명 |
| 라벨 | 워크스페이스 라벨 중 선택, 최대 50개 |
| 시작일·기한 | 시작일이 기한보다 뒤가 되지 않도록 지정 |

## 빠르게 시작하기

자주 반복하는 업무는 생성 창의 **템플릿**을 확인합니다. **결정기록**, **버그 리포트**, **회의록** 양식이 제공됩니다. 선택하면 본문 양식이 들어가고, 대응하는 라벨이 있으면 함께 적용됩니다. 이미 쓴 설명이 있다면 양식은 그 아래에 더해지므로 중복 내용을 정리합니다.

결정기록에는 **맥락 → 결정 → 검토한 대안**을 채웁니다. 무엇을 선택했는지와 고르지 않은 대안의 이유를 적고, 후속 작업을 관련 업무로 연결합니다. 결정기록은 일반 업무에 시스템 라벨로 분류되며 **결정기록** 뷰에서 모아 볼 수 있습니다. 버그 리포트에는 재현 순서·기대 동작·실제 동작·환경을, 회의록에는 참석자·안건·결정 사항·담당자별 할 일을 채웁니다.

템플릿 선택 뒤에도 제목·담당자·상태가 이번 업무에 맞는지 점검합니다. **템플릿 없음**으로 되돌릴 때는 아직 수정하지 않은 양식과 템플릿이 붙인 라벨이 제거될 수 있으므로 본문을 확인합니다. 템플릿은 업무 유형을 대신하지 않습니다.

## 저장할 수 없을 때

빈 제목이면 제목을 입력합니다. 상위 업무를 요구하는 유형이면 같은 범위의 허용된 상위를 선택합니다. 권한 안내가 나오면 워크스페이스의 업무 작성 권한을 확인합니다. 제출 중에는 중복해서 누르지 말고, 목록에서 생성 여부를 확인한 뒤 다시 시도합니다.

이후 수정과 저장 방식은 [상태와 설명 고치기](mZMhRhMpGo.md)에서 이어집니다.
