# 일정 만들고 참석자 정하기

회의·점검처럼 시각과 참석자가 중요한 일은 **스케줄**에서 관리합니다. 해야 할 작업을 정리하는 이슈와 목적이 다릅니다.

## 일정 만들기

1. 워크스페이스 또는 프로젝트의 **스케줄**을 엽니다. **오늘**, 이전·다음 달로 날짜 범위를 이동할 수 있습니다.
2. **스케줄 만들기**를 누르고 제목과 설명을 입력합니다.
3. **일시**에서 날짜를 정하고 시작·끝 시간을 입력합니다. 하루 전체 일정이면 **종일**을 켭니다.
4. **참석자**에서 참여할 사람을 선택하고 필요한 라벨을 붙입니다.
5. **알림**을 확인하고 **일정 만들기**를 누릅니다.
6. 해당 날짜의 일정을 열어 제목·날짜·시간·참석자를 확인합니다.

![일정의 시간·참석자·알림을 확인하는 상세 패널](attachment:lF8kzTCXkS)

## 입력 기준

| 항목 | 조건 |
| --- | --- |
| 제목·설명 | 제목 필수 최대 200자, 설명 선택 최대 20,000자 |
| 날짜·시간 | 시간을 가진 일정은 시작보다 종료가 뒤여야 함. 날짜를 지정해야 달력에서 찾을 수 있음 |
| 종일 | 시간 대신 날짜로 다루는 일정에 사용 |
| 참석자 | 최대 20명. 업무 담당자와 달리 이 일정에 참여할 사람 |
| 알림 | 생성 창의 기본 표시는 10분 전. 필요한 시점을 선택 |

입력한 날짜·시간이 속성에 표시되는지 확인한 뒤 생성합니다. 날짜가 없거나 다른 달에 있으면 현재 달력에서 안 보일 수 있습니다. 초대 이메일이 자동 전송된다고 가정하지 말고 팀의 전달 방식도 확인합니다.

## 일정 고치기

달력에서 일정을 눌러 상세를 엽니다. 일시·참석자·알림은 각 속성에서 바꾸고, 제목·설명 편집은 저장 막대에서 저장합니다. 일정 검색과 필터로 대상을 좁힐 수 있습니다. 반복 일정의 회차 변경은 [반복과 알림](m1gthcnUYP.md)을 먼저 확인합니다.
