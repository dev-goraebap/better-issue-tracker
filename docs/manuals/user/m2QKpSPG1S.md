# 복사·Markdown·PDF와 매뉴얼 원본 다루기

매뉴얼 페이지 상단 **페이지 도구**에서 목적에 맞게 복사하거나 내보냅니다. Markdown·원본·PDF는 담는 범위와 다시 편집하는 방식이 다릅니다.

![페이지 도구의 복사·내보내기·PDF 메뉴](attachment:kXZiGxI3Av)

## 어떤 형식을 고를까요?

| 도구 | 용도와 결과 |
| --- | --- |
| Markdown 복사 | 현재 페이지의 Markdown을 클립보드로 복사 |
| 페이지 링크 복사 | 같은 페이지로 다시 들어갈 주소 공유 |
| Markdown 내보내기 | 현재 페이지를 Markdown으로 저장. 이미지가 있으면 원본 이미지와 함께 ZIP으로 저장 |
| 매뉴얼 원본 내보내기 | 책의 구조·Markdown·이미지가 들어 있는 BIT 매뉴얼 파일 저장 |
| 현재 페이지 PDF로 저장 | 지금 읽는 페이지를 인쇄 경로로 저장 |
| 전체 매뉴얼 PDF로 저장 | 책의 페이지를 순서대로 인쇄 경로로 저장 |

## PDF로 저장하기

1. 페이지 도구에서 현재 페이지 또는 전체 매뉴얼 PDF를 선택합니다.
2. 브라우저가 연 인쇄 창에서 대상 프린터를 **PDF로 저장**으로 고릅니다.
3. 미리보기에서 표·이미지와 페이지 나눔을 확인한 뒤 저장합니다.

창이 안 열리면 팝업 허용과 브라우저 인쇄 지원을 확인합니다. PDF는 읽고 전달할 용도이고, 다시 BIT에서 편집할 사본이 필요하면 매뉴얼 원본을 사용합니다. 브라우저와 운영체제에 따라 인쇄 선택 항목은 달라질 수 있습니다.

## 원본을 다른 공간으로 가져오기

1. 원본 파일을 먼저 내보냅니다.
2. 대상 워크스페이스 또는 프로젝트의 **매뉴얼** 목록으로 이동합니다.
3. **매뉴얼 도구 → 매뉴얼 가져오기**에서 파일을 선택합니다.
4. 검사 결과를 확인하고 **가져오기**를 누릅니다. 새 책이 생성되었는지 확인합니다.

![매뉴얼 원본 파일을 선택하는 가져오기 창](attachment:PrlUNzHl9c)

가져오기는 기존 책을 덮어쓰지 않고 새 매뉴얼로 만듭니다. 원본 계정의 권한·댓글·감사 기록을 그대로 이식하는 백업 복원 기능은 아닙니다. BIT 매뉴얼 파일 형식과 200MiB 패키지 한도, 책의 본문·이미지 한도를 함께 검사합니다. 일반 Markdown 파일이나 PDF를 이 창으로 가져올 수는 없습니다.

복사가 실패하면 브라우저의 클립보드 권한을 확인하고, 파일 생성이 실패하면 안내와 이미지 접근 상태를 확인합니다.

본문에 적어 둔 링크는 가져온 공간에서도 열리는지 확인합니다. 다른 공간이나 원본 책을 가리키는 링크는 필요한 경우 바꿉니다.
