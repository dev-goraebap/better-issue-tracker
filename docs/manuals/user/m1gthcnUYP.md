# 반복 일정과 알림 관리하기

정기 점검이나 주간 회의는 반복 규칙으로 만들 수 있습니다. 반복 규칙과 개별 회차를 구분해 바꿉니다.

## 반복 설정하기

1. 일정의 **반복**을 엽니다.
2. **매일 / 매주 / 매월** 중 주기를 고릅니다.
3. 간격을 입력합니다. 매주라면 요일도 선택합니다.
4. 필요하면 **끝나는 날**을 지정합니다. 무기한 반복이 필요한지 먼저 확인합니다.
5. 설정을 닫고 표시된 반복 요약을 확인한 뒤 일정을 저장합니다.

![매주 반복의 간격·요일·종료일 선택](attachment:OHvd3BsTtq)

간격은 1~52 사이입니다. 주간 요일은 실제 개최일에 맞춰 선택합니다. 반복을 없애려면 **반복 안 함**을 사용합니다. 회차를 편집하거나 삭제할 때는 화면이 묻는 적용 범위를 읽고, 이번 회차와 이후 반복 전체를 혼동하지 않습니다.

## 알림 확인하기

알림 시점은 일정의 **알림** 속성에서 고릅니다. 참석자와 시작 시각이 올바른지 함께 확인합니다. 메일 서버나 브라우저 알림 설정이 없으면 이메일·운영체제 알림이 온다고 기대하지 말고 BIT의 **알림**을 확인합니다.

시간대가 바뀐 기기에서는 표시 시각을 확인합니다. 하루 종일 일정과 시각이 있는 일정을 섞지 말고, 다른 지역과 협업할 때는 설명에도 기준 시간대를 적어 둡니다.

## 원치 않는 반복이 생겼을 때

같은 회의를 다시 만들기 전에 기존 반복 규칙이 있는지 검색합니다. 일회성 예외는 해당 회차의 적용 범위를 확인해 수정하고, 회의 자체가 끝났다면 규칙의 종료일 또는 반복 안 함을 사용합니다. 날짜가 안 보이면 검색·필터와 표시 달도 확인합니다.
