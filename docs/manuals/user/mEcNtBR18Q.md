# 매뉴얼 만들고 목록에서 관리하기

사용법·운영 절차·개발 지침처럼 반복해서 참고할 내용을 매뉴얼로 만듭니다. 한 매뉴얼은 섹션과 페이지로 구성되며 왼쪽 탐색, 본문, 현재 페이지 목차로 읽습니다.

## 매뉴얼 만들기

1. 둘 공간을 먼저 고릅니다. 공통 지침은 워크스페이스, 특정 제품 지침은 프로젝트에서 **매뉴얼**을 엽니다.
2. 헤더의 **매뉴얼 만들기**를 누릅니다.
3. 창의 **소속**을 확인하고 이름·설명을 입력합니다.
4. 아이콘과 색을 골라 **매뉴얼 만들기**를 누릅니다.
5. 생성된 책을 열고 [페이지 작성](mOxUVmY0BB.md)을 시작합니다.

![소속과 이름·설명·아이콘을 정하는 생성 창](attachment:WTR4tWbuWf)

| 입력 | 조건 |
| --- | --- |
| 이름 | 필수, 공백만 불가, 최대 120자 |
| 설명 | 선택, 최대 400자. 독자와 담을 범위를 짧게 설명 |
| 아이콘·색 | 목록에서 책을 구분할 표식 |

## 목록에서 찾기

![이름·설명·소속·페이지 수로 읽는 매뉴얼 목록](attachment:qlwzygbijy)

상단 검색으로 이름·설명을 찾고 **필터**로 범위를 확인합니다. **표시**에서 정렬을 정합니다. 워크스페이스 범위에서는 공통 책과 프로젝트 책의 소속을 확인하고, 프로젝트 범위에서는 해당 프로젝트의 책을 관리합니다.

행 끝 **더보기** 또는 책 안의 **설정**으로 제공되는 이름·설명·아이콘·색 관리 동작을 사용합니다. 같은 이름의 책을 여러 개 만들기 전에 기존 책을 검색합니다. 매뉴얼 편집에는 문서 작성 권한이 필요합니다.

회의록이나 개별 참고 파일은 [리소스](m1WJ1ML0uY.md)에 두고, 여러 페이지로 안내해야 할 사용법과 지침은 매뉴얼에 정리하면 찾기 쉽습니다.
