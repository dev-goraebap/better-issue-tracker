# 페이지 작성하고 목차 구성하기

페이지 하나에는 독자가 끝낼 수 있는 작업이나 하나의 주제를 담습니다. 예를 들어 ‘문의 처리’ 섹션 아래 ‘문의 접수 후 확인할 내용’, ‘답변 전 확인하기’를 나눕니다.

## 페이지 추가와 편집

1. 매뉴얼을 열고 탐색 아래 **페이지 추가**를 누릅니다.
2. 제목과 섹션을 정합니다. 아직 섹션이 없다면 최상위에 만들 수 있습니다.
3. 본문을 작성합니다. **본문 편집**, **Markdown**, **미리보기**를 오가며 형식과 결과를 확인합니다.
4. 필요한 화면은 **이미지 추가**로 넣습니다. 이미지 바로 아래에 독자가 확인할 위치나 결과를 설명합니다.
5. **저장**을 누르고 탐색에서 페이지를 다시 열어 결과를 확인합니다.

![Markdown 원문과 페이지 제목·섹션을 편집하는 화면](attachment:IKJOr0Jhzs)

페이지 제목은 필수 최대 160자, 섹션 제목은 최대 100자입니다. 페이지 본문은 최대 200,000자이며 책 전체 본문은 최대 5,000,000자입니다. 한 책에는 섹션 100개·페이지 500개·이미지 500개까지 둘 수 있습니다. 긴 본문을 한 페이지에 몰기보다 작업별로 나눕니다.

## 구성과 순서 정하기

1. 탐색 아래 **구성 편집**을 엽니다.
2. 필요한 섹션을 추가하거나 제목을 고칩니다.
3. 손잡이로 섹션·페이지를 끌어 정렬합니다. 페이지는 다른 섹션 제목 아래로 옮길 수 있습니다.
4. 키보드로는 손잡이에서 **Alt+위/아래**를 사용합니다. 끌기 중 **Esc**는 이동을 취소합니다.
5. **구성 저장**으로 반영합니다. **취소**는 이번 구성 변경을 버립니다.

## 이미지와 충돌 다루기

화면 사진은 읽을 수 있는 원본을 사용합니다. 매뉴얼 이미지 전체는 100MiB 한도가 있고 파일별 업로드 제한도 별도로 적용됩니다. 큰 사진을 무조건 축소하기보다 중요한 입력 영역을 알아볼 수 있게 촬영하고 문맥이 필요한 화면도 함께 둡니다.

다른 사람이 수정했다는 안내가 나오면 초안 내용을 먼저 복사한 뒤 최신 내용을 불러와 합칩니다. 저장 실패 때 입력이 남아 있더라도 서버에 저장된 것으로 간주하지 않습니다. 편집 중 다른 페이지를 추가하려면 현재 편집을 저장하거나 취소합니다.
