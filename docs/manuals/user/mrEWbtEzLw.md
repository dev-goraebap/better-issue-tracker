# 프로젝트 찾기·즐겨찾기·보관하기

프로젝트 목록에서 진행 중인 프로젝트를 찾고, 자주 쓰는 프로젝트를 왼쪽 메뉴에 고정할 수 있습니다.

## 프로젝트 열기

1. 워크스페이스 범위에서 **프로젝트**를 엽니다.
2. 검색으로 이름을 찾거나 **진행 중 / 보관됨** 탭을 선택합니다.
3. 프로젝트 이름을 누릅니다. 왼쪽 위 이름과 메뉴가 선택한 프로젝트로 바뀌는지 확인합니다.

![프로젝트 목록의 이름·키·설명과 즐겨찾기](attachment:QOgADY4WcH)

제목 옆의 연한 `WEB` 같은 문자는 프로젝트 키입니다. 이슈 번호 앞에 붙으며, 프로젝트의 표시 이름과는 다릅니다.

## 자주 쓰는 프로젝트 정리하기

프로젝트 행의 별을 선택하면 워크스페이스 메뉴의 프로젝트 아래에 바로 표시됩니다. 목록의 손잡이를 끌어 순서를 바꿉니다. 즐겨찾기는 프로젝트 자체를 복사하거나 다른 사람의 접근 권한을 바꾸지 않습니다.

![프로젝트 상단 전환 메뉴](attachment:uGbnPzpCUA)

프로젝트 포커스에서도 왼쪽 위 전환 메뉴로 다른 프로젝트를 열 수 있습니다. 상위 워크스페이스 이름을 선택하면 전체 범위로 돌아갑니다.

## 설정과 보관

1. 프로젝트 행 끝의 **더보기**를 엽니다.
2. **설정 바로가기**에서 이름·설명·아이콘·색 등을 관리합니다.
3. 작업을 잠시 끝낸 프로젝트는 **보관**을 선택하고 확인합니다.
4. 다시 사용할 때는 **보관됨** 탭에서 프로젝트를 찾아 보관을 해제합니다.

![프로젝트 행의 설정·보관·삭제 메뉴](attachment:F1zRUToEiF)

보관한 프로젝트는 자료를 확인할 수 있지만 변경 작업이 제한됩니다. 보관 안내가 나오면 관리자에게 해제를 요청합니다. **삭제**는 보관과 다른 동작이므로, 단순히 목록에서 쉬게 두려면 보관을 사용합니다. 삭제된 항목을 찾는 일반 목록 탭은 제공하지 않습니다.

생성·설정·보관 메뉴는 설정을 바꿀 권한이 있는 사용자에게 제공됩니다. 새 프로젝트는 [프로젝트 만들기](yl8U8QA59h.md)를 참고합니다.
