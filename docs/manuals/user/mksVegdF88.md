# 알림 확인하고 원래 작업으로 이동하기

왼쪽 위 종 모양 **알림**에서 나와 관련된 변경을 확인합니다. 알림 목록은 업무의 상태 목록과 다릅니다.

## 알림 읽기

1. **알림**을 엽니다.
2. 안 읽은 항목과 내용을 확인합니다.
3. 항목을 열어 어떤 업무에서 생긴 변경인지 확인하고 원래 업무로 이동합니다.
4. 제공되는 읽음 처리로 목록을 정리합니다.

![담당자 지정 알림과 연결된 업무](attachment:zvDATC8Kyb)

알림을 읽는 것은 이슈 완료나 승인 처리가 아닙니다. 실제 작업을 끝냈다면 이슈의 상태와 결과 댓글을 따로 갱신합니다. 삭제되었거나 접근할 수 없는 대상은 원래 내용이 열리지 않을 수 있습니다.

알림이 기대한 방식으로 오지 않으면 담당자·참석자·일정 시각과 현재 워크스페이스를 확인합니다. 이메일·브라우저·운영체제 알림은 서버와 기기의 별도 설정에 따라 달라지므로, 모든 환경에서 자동 이메일이 온다고 생각하지 않습니다.
