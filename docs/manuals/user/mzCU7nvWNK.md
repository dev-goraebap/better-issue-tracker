# 라벨과 업무 유형 관리하기

라벨은 여러 업무·자료에 붙이는 분류이고, 업무 유형은 업무의 종류와 상위 관계 규칙을 정합니다. 상태는 진행 단계이므로 세 개념을 구분합니다.

## 라벨 만들고 정리하기

1. **워크스페이스 관리 → 라벨**을 엽니다.
2. 라벨 추가 동작에서 이름과 색을 정합니다.
3. 저장한 뒤 이슈나 문서의 라벨 선택에서 확인합니다.
4. 제공되는 손잡이로 순서를 바꾸고 기존 라벨은 행의 수정 동작으로 고칩니다.

![기본 시스템 라벨과 라벨 관리 화면](attachment:EUv23BScsB)

**결정기록**은 시스템 라벨이며 이름 변경·삭제가 제한됩니다. 일반 라벨과 같은 방식으로 지우려 하지 않습니다. 프로젝트마다 별도 라벨 체계를 만드는 대신 워크스페이스의 라벨을 사용합니다.

## 업무 유형과 상위 규칙

1. **업무 유형** 탭을 엽니다.
2. 에픽·스토리·작업·버그 등 현재 유형을 확인합니다.
3. 유형을 추가하거나 수정하면서 이름·아이콘·기본값과 상위 업무 규칙을 정합니다.
4. 허용 상위 유형과 상위 필수 여부가 팀 구조에 맞는지 확인하고 저장합니다.

![스토리 유형의 허용 상위와 필수 여부 설정](attachment:YtaK2dBZqZ)

기본 스토리는 에픽을 상위로 요구합니다. ‘상위 없음’을 허용하는 업무와 반드시 상위를 골라야 하는 업무를 구분합니다. 사용 중인 유형을 바꾸거나 없앨 때는 기존 업무에 미치는 안내를 확인하고, 유형 이름만 바꾸려는지 구조까지 바꾸려는지 구분합니다.

업무 생성에서 상위 선택 오류가 반복되면 규칙을 임의로 풀기보다 현재 업무가 어떤 유형이어야 하는지 먼저 확인합니다. 설정·유형 관리는 해당 권한이 있어야 하고, 라벨 관리는 별도 라벨 권한을 따릅니다.

라벨 이름과 업무 유형 이름은 각각 필수 최대 32자입니다. 중복이나 사용 중인 항목의 제약으로 저장·삭제가 거절되면 안내를 확인하고 기존 항목을 고칠지 새 항목이 필요한지 판단합니다.
