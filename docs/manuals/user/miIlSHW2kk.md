# 매뉴얼 읽고 개선 의견 남기기

왼쪽은 책 전체의 페이지 탐색, 오른쪽 목차는 현재 페이지 안의 제목입니다. 본문을 읽다가 필요한 절로 바로 이동할 수 있습니다.

## 내용 찾기

1. 목록에서 매뉴얼을 열고 왼쪽 페이지를 선택합니다.
2. 상단 검색 아이콘으로 책 안의 제목·본문에 있는 말을 찾습니다.
3. 현재 페이지 목차를 눌러 원하는 절로 이동합니다. 목차가 안 보이면 **페이지 도구 → 현재 페이지 목차**를 엽니다.
4. 아래의 **이전 / 다음**으로 이어서 읽습니다.

![페이지 탐색과 본문을 나누어 읽는 화면](attachment:hIO6N1jdOM)

탐색과 본문 사이 경계를 끌어 왼쪽 너비를 바꿀 수 있습니다. 방향키로도 조절하며 두 번 누르면 기본 너비로 돌아갑니다. 작은 화면에서는 **탐색 / 목차**를 열어 이동합니다. 본문을 스크롤해도 탐색은 별도로 유지됩니다.

## 개선 의견 남기기

1. 상단 **페이지 댓글**을 엽니다.
2. 잘못된 설명의 위치와 어떤 점을 바꾸면 좋을지 적습니다.
3. **댓글 남기기**를 누르고 저장된 의견을 확인합니다.
4. 수정한 사람은 의견을 검토한 뒤 **해결 처리**합니다. **해결됨**에서 다시 보거나 다시 열 수 있습니다.

![페이지에 남긴 개선 의견과 해결 처리 버튼](attachment:NLYTOPxmtq)

댓글은 현재 페이지에 붙습니다. 다른 페이지의 문제라면 해당 페이지를 연 뒤 남깁니다. 보기 전용 사용자는 내용을 읽을 수 있지만 댓글 추가나 해결 같은 변경은 할 수 없습니다. 편집 버튼이 필요하면 관리자에게 문서 작성 권한을 요청합니다.

본문 공유와 파일 저장은 [복사·내보내기](m2QKpSPG1S.md)를 참고합니다. 링크 전달은 받는 사람의 워크스페이스 접근 권한을 자동으로 만들지 않습니다.
