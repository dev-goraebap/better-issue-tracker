# 문서·폴더·첨부 자료 관리하기

리소스에는 회의 메모, 참고 문서, 업무 근거처럼 필요할 때 찾아볼 자료를 둡니다. 체계적인 사용법을 여러 페이지로 제공하려면 매뉴얼을 사용합니다.

## 폴더와 문서 만들기

1. 워크스페이스 또는 프로젝트의 **리소스**를 엽니다.
2. **만들기 → 새 폴더**로 자료를 묶을 폴더를 만듭니다.
3. 넣을 위치에서 **만들기 → 새 문서**를 선택합니다.
4. 제목과 Markdown 기반 본문을 작성하고, 필요한 파일을 첨부합니다.
5. 저장한 뒤 제목·내용·첨부가 남았는지 확인합니다.

![새 문서와 새 폴더를 만드는 리소스 메뉴](attachment:sbyb4vI9K7)

| 항목 | 조건 |
| --- | --- |
| 문서 제목 | 필수, 최대 200자 |
| 문서 본문 | 최대 200,000자 |
| 폴더 이름 | 필수, 최대 128자 |
| 첨부 | 파일별 크기·허용 형식 적용. 업로드 완료 뒤 저장 |

![참고 파일을 첨부한 회의 메모 문서](attachment:BCEZ9jlu3B)

## 문서 수정과 자료 연결

문서를 열고 제목·본문의 편집 동작으로 수정한 뒤 저장합니다. 라벨로 자료의 주제를 표시하고, 하단 **업무 연결**로 이슈를 연결합니다. 다른 문서가 근거라면 **문서 참조**를 사용합니다. 원본 자료의 위치를 남겨 같은 파일을 반복 복사하지 않도록 합니다.

## 파일을 사용할 때

현재 리소스 만들기 메뉴는 **새 문서 / 새 폴더**를 제공합니다. Excel·Word·PowerPoint·한글 등은 문서 본문이나 댓글에 첨부해 맥락과 함께 관리합니다. 해당 파일 링크로 다운로드한 뒤 맞는 프로그램에서 엽니다. 모든 형식을 리소스 안에서 직접 편집하거나 미리 볼 수 있는 것은 아닙니다.

목록의 제공되는 이동 동작으로 폴더 안팎을 정리할 때는 목적 위치를 확인합니다. 삭제는 정리·이동과 다르므로 확인 창에서 문서와 폴더의 대상을 읽습니다. 작성·정리에는 문서 작성 권한이 필요합니다.
