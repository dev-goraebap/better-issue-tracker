# 워크스페이스 이름과 메뉴 구성 바꾸기

워크스페이스 관리에서는 팀 이름과 탐색 메뉴를 정리합니다. 표시 이름을 바꿔도 기능의 주소와 권한이 다른 기능으로 바뀌지는 않습니다.

## 이름 바꾸기

1. 워크스페이스 범위의 **워크스페이스 관리 → 일반**을 엽니다.
2. 이름을 고치고 **저장**합니다. 이름은 필수, 최대 64자입니다.
3. 왼쪽 위와 상단 경로에 새 이름이 표시되는지 확인합니다.

## 메뉴 이름과 순서 바꾸기

1. 일반 설정의 메뉴 구성 영역에서 편집을 시작합니다.
2. 이슈·스케줄·매뉴얼·리소스·멤버·프로젝트의 표시 이름을 팀 용어에 맞게 고칩니다.
3. 손잡이를 끌어 메뉴 순서를 바꿉니다. 키보드는 손잡이에서 **Alt+위/아래**를 사용합니다.
4. **저장**으로 반영하거나 **취소**로 되돌립니다.

![메뉴 이름과 드래그 손잡이가 있는 구성 영역](attachment:dHM4zJ7Np5)

메뉴 이름은 공백만 입력할 수 없고 최대 32자입니다. 워크스페이스와 프로젝트 범위의 메뉴 구성은 해당 범위에 맞춰 관리합니다. 메뉴를 ‘가이드’로 바꾸어도 매뉴얼의 주소나 문서 작성 권한은 유지됩니다.

## 소유권과 위험한 작업

워크스페이스 삭제와 소유권 이전은 소유자 권한 영역입니다. 조직의 관리자를 바꾸는 경우 일반 멤버의 역할 변경과 구분하고, 이전 받을 사람·현재 역할·확인 문구를 점검합니다. 작업 중인 팀의 이름만 바꾸려는데 삭제를 사용할 필요는 없습니다.

일반 멤버에게 저장 동작이 제공되지 않으면 관리자에게 요청합니다. 메뉴 배치나 이름 변경은 팀 전체가 사용하는 탐색에 영향을 주므로, 자주 쓰는 이름을 정해 일관되게 유지합니다.
