# 검색·필터·뷰로 이슈 찾기

같은 업무를 목록·보드·날짜 중심 화면으로 볼 수 있습니다. 뷰는 업무의 복사본이 아니라 조건과 표시 방식을 저장한 화면입니다.

## 조건으로 좁히기

1. **이슈**에서 작업할 워크스페이스 또는 프로젝트를 확인합니다.
2. 상단 검색 아이콘을 눌러 찾을 말을 입력합니다.
3. **필터**에서 상태·우선순위·사람·라벨·유형을 선택합니다.
4. 목록과 하단 개수가 원하는 범위인지 확인합니다. 적용된 조건은 상단 필터에서 바꾸거나 지웁니다.

![진행 중 상태만 고르는 필터](attachment:UFgTM9gOis)

조건 때문에 안 보이는 업무는 삭제된 것이 아닐 수 있습니다. **모두 지우기**로 조건을 풀고 현재 프로젝트와 뷰를 다시 확인합니다.

## 표시 방식 바꾸기

**표시**에서 보기 방식, 정렬 기준·방향, 그룹, 보여줄 속성을 정합니다.

![보기 방식·정렬·그룹·표시 속성 선택](attachment:l0LhldiGYX)

| 보기 방식 | 살펴볼 때 |
| --- | --- |
| 리스트 | 제목과 속성을 빠르게 훑고 업무를 열 때 |
| 칸반 | 상태별로 진행량을 확인하고 카드를 옮길 때 |
| 캘린더 | 날짜가 있는 업무를 달력에서 볼 때 |
| 타임라인 | 기간과 배치를 비교할 때 |
| 카드 | 개별 업무를 카드 단위로 볼 때 |
| 히스토리 | 시간 흐름에 따라 업무를 살펴볼 때 |

날짜 중심 화면에서 업무가 안 보이면 날짜 미지정 여부와 표시 기간도 확인합니다. 스케줄 메뉴는 일정 전용 달력이므로 이슈 뷰와 구분합니다.

## 보드에서 상태 이동하기

![상태별로 배치된 진행 보드](attachment:VkVTyC1iBt)

카드를 원하는 칸으로 끌어 놓습니다. 키보드는 스페이스로 집고 화살표로 옮긴 뒤 스페이스 또는 Enter로 놓으며 Esc로 취소합니다. 터치에서는 길게 눌러 집습니다. 이동한 칸과 상세의 상태가 일치하는지 확인합니다. 읽기 전용 사용자는 변경할 수 없습니다.

## 조건을 뷰로 저장하기

조건을 바꾼 뒤 **뷰로 저장**을 누르고 이름·설명을 정합니다. **나만 보기**를 켜면 개인 뷰로 관리합니다. 만들고 나면 상단 뷰 탭에서 다시 열 수 있습니다.

![조건을 이름 붙여 저장하는 새 뷰 영역](attachment:uYkJoes4YD)

기존 뷰를 수정하는 경우 새로 저장하는지 기존 설정을 갱신하는지 버튼을 확인합니다. 탭 옆 **뷰 메뉴**에서 제공되는 관리 동작을 사용하고, 공용 뷰를 바꿀 때는 다른 사람이 쓰는 조건인지 확인합니다.
