# 로그인하고 작업 공간 선택하기

BIT 계정 하나로 참여한 여러 워크스페이스를 오갈 수 있습니다. 같은 계정이어도 워크스페이스마다 역할과 자료가 다릅니다.

## 로그인하기

1. 팀에서 사용하는 BIT 주소를 엽니다.
2. **이메일**과 **비밀번호**를 입력하고 **로그인**을 누릅니다.
3. 워크스페이스 목록이 표시되면 작업할 공간을 선택합니다. 마지막 공간이 열렸다면 왼쪽 위 전환 메뉴에서 다른 공간을 선택합니다.

![참여한 워크스페이스를 고르는 목록](attachment:VJ2tF3nsRS)

이름 옆 역할은 그 공간에서의 내 역할입니다. 다른 워크스페이스의 권한이 함께 적용되지는 않습니다.

## 새 워크스페이스 만들기

팀의 자료를 분리해 관리하려면 워크스페이스 목록의 **워크스페이스 추가**를 누릅니다. 이름을 입력하고 생성하면 내가 새 공간의 소유자가 됩니다. 이름은 필수이며 최대 64자입니다. 기존 팀에 들어가려는 경우 새 공간을 만들기보다 [초대받고 참여하기](m7V2CXMoi9.md)를 따릅니다.

![새 워크스페이스 이름 입력 창](attachment:WYvfVW1JlX)

## 프로젝트와 워크스페이스 사이 이동하기

프로젝트를 열면 왼쪽 위가 프로젝트 이름으로 바뀌고, 메뉴와 내용도 그 프로젝트에 맞춰집니다. 전환 메뉴에서 상위 워크스페이스 이름을 선택하면 워크스페이스 범위로 돌아갑니다. **프로젝트 목록**에서는 다른 프로젝트를 찾을 수 있습니다.

## 로그인에 문제가 있을 때

이메일의 오타와 비밀번호를 확인합니다. 반복해서 실패해 잠시 로그인이 제한되었다면 안내에 따라 기다린 뒤 다시 시도합니다. 새 계정은 워크스페이스 초대로 참여하며, 비밀번호 복구는 인스턴스 관리자에게 요청합니다. 비밀번호 변경이 필요하다는 화면이 나오면 변경을 완료한 뒤 작업합니다.

공용 기기에서는 작업을 마치고 **내 설정 → 로그아웃**을 누릅니다. 다른 기기의 로그인까지 종료하려면 [계정 보안](mJBFi2AUze.md)을 확인합니다.
