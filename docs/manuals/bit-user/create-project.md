함께 진행할 업무를 프로젝트에 모읍니다. 프로젝트를 만들 수 있는 권한이 필요합니다.

## 프로젝트 등록하기

1. 왼쪽 ‘프로젝트’ 옆의 만들기 버튼을 누르세요.
2. 프로젝트 이름을 입력하세요.
3. 업무 번호에 사용할 ‘키’를 입력하세요. 영문 대문자와 숫자 2~10자를 사용합니다.
4. 필요한 설명을 입력하고 ‘프로젝트 만들기’를 누르세요.

![프로젝트 이름과 업무 번호에 사용할 키를 입력합니다](images/project-create.jpg)

## 등록 결과 확인하기

왼쪽 메뉴에 프로젝트가 추가됩니다. 키가 ‘FDBK’라면 그 프로젝트에서 만드는 업무는 ‘FDBK-1’처럼 표시됩니다. 이후 설명의 사진은 ‘웹사이트 개선(DEMO)’ 프로젝트를 사용합니다.

## 만들 수 없을 때

이미 사용 중인 키라면 다른 키를 입력하세요. 만들기 버튼이 없다면 워크스페이스 관리자에게 권한을 확인하세요.
