업무를 이해하는 데 필요한 문서를 연결해 두면, 업무와 참고 내용을 오가기 쉽습니다.

## 업무 연결하기

1. 연결할 문서를 여세요.
2. 본문 아래 ‘업무 연결’을 누르세요.
3. 업무 제목이나 번호로 검색하세요.
4. 연결할 업무를 선택하고 ‘연결’을 누르세요.

![문서 아래에 관련 업무와 현재 상태가 표시됩니다](images/document-link.jpg)

## 연결 확인하기

‘연결된 업무’에 제목과 번호가 나타납니다. 업무 링크를 눌러 현재 상태와 댓글을 확인할 수 있습니다.

## 검색 결과가 없을 때

업무 번호와 워크스페이스가 맞는지 확인하세요. 접근할 수 없는 업무는 연결 대상으로 보이지 않을 수 있습니다. 본문에 단순히 번호를 적는 것과 연결 기능을 사용하는 것은 다릅니다.
