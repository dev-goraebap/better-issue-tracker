# BIT 사용자 매뉴얼 원본

`manifest.json`은 섹션과 페이지 순서, 각 Markdown 파일은 제목을 제외한 본문이다. `images/`에는 시험 계정으로 촬영한 실제 화면의 JPEG 원본을 둔다. 본문 이미지 경로는 이 폴더를 기준으로 한다.

저장소 루트에서 다음 명령으로 BIT 매뉴얼 가져오기 파일을 만든다.

```powershell
node scripts/build-bit-user-manual.mjs
```

기본 결과는 `.tmp/bit-user-manual.bit-manual.json`이다. 출력 경로를 첫 인자로 지정할 수 있다. 생성기는 원본 사진을 재압축하지 않고 포함하며, 가져오기 한도인 4MB를 넘으면 중단한다.

로컬 BIT의 프로젝트 매뉴얼 목록에서 **매뉴얼 도구 → 매뉴얼 가져오기**로 파일을 선택한다. 기존 매뉴얼을 덮어쓰지 않고 새 항목으로 추가한다. 브라우저에서 본문을 수정한 뒤에는 **페이지 도구 → 매뉴얼 원본 내보내기**로 최신 원본을 보관할 수 있다. 원본 내보내기와 가져오기는 댓글을 포함하지 않는다.

현재 매뉴얼 화면은 브라우저별 로컬 저장이다. 이 파일을 생성하거나 가져와도 운영 서버에 게시되지는 않는다. 내용 근거와 촬영·검수 범위는 BIT-137, 가져오기·내보내기 검증은 BIT-144에 기록한다.
