API 키는 에이전트나 스크립트가 내 업무 권한으로 BIT에 접근하도록 할 때 사용합니다. 키를 아는 대상에게 내 권한으로 작업할 수 있는 접근을 주는 것이므로 필요한 곳에만 전달하세요.

## 키 만들기

1. ‘내 설정 → API 키’를 여세요.
2. ‘새 키’를 누르세요.
3. 용도를 알아볼 이름과 필요한 에이전트 이름을 입력하세요.
4. 만료 기간을 선택하고 내 비밀번호를 입력하세요.
5. ‘만들기’를 누르세요.

![키의 이름·만료 기간과 본인 확인을 입력합니다](images/api-key-form.jpg)

## 키 보관과 폐기

키 원문은 생성 직후 한 번만 보입니다. 필요한 연결 도구의 보안 설정에 보관하고, 문서·댓글·스크린샷에 노출하지 마세요. 더 이상 쓰지 않거나 노출된 키는 해당 키 메뉴의 ‘폐기’로 중단하세요.

만료되거나 폐기된 키, 비밀번호 변경으로 해제된 키는 다시 사용할 수 없습니다. 계정 보안 설정처럼 API 키로 할 수 없는 동작도 있습니다.
