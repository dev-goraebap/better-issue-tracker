## 버튼이나 프로젝트가 보이지 않습니다

현재 워크스페이스와 계정이 맞는지 확인하세요. 역할과 참여 프로젝트에 따라 볼 수 있는 항목과 수정 동작이 다릅니다. 관리자에게 업무 번호와 진입 위치를 함께 알려 주세요.

## 저장했는데 목록에서 찾을 수 없습니다

검색어와 필터를 지우고, 저장한 프로젝트·폴더를 확인하세요. 업무 번호나 문서 제목으로 다시 찾아보세요. 다른 사람이 먼저 수정했다는 안내는 최신 내용을 확인한 뒤 처리하세요.

## 초대 링크가 작동하지 않습니다

원래 전달받은 링크를 다시 여세요. 만료되었거나 이미 사용된 링크라면 새 초대를 요청하세요. 초대 이메일과 로그인 이메일이 같아야 합니다.

## 사진이 작거나 내용이 잘립니다

사진을 눌러 원본을 확대하세요. 긴 표와 코드는 해당 영역을 가로로 이동해 볼 수 있습니다. 브라우저 확대 비율이 너무 높다면 본문 폭도 함께 확인하세요.

## PDF 저장 창이 열리지 않습니다

브라우저의 팝업·인쇄 설정을 확인하고 다시 시도하세요. Chrome 등 일반 브라우저에서 같은 페이지를 열어 확인할 수 있습니다. 저장 전에는 인쇄 미리보기에서 글꼴·사진·표와 페이지 나눔을 확인하세요.

## 다른 브라우저에서 매뉴얼이 보이지 않습니다

현재 로컬 매뉴얼 화면의 저장은 브라우저별입니다. 해당 브라우저에서 매뉴얼 파일을 가져오세요. 링크를 복사하는 것만으로 내용과 이미지가 다른 브라우저에 저장되지는 않습니다.
