업무 설명에는 목적과 완료 기준을, 댓글에는 진행 상황과 확인 결과를 남깁니다.

## 설명 편집하기

업무 상세에서 제목과 설명을 편집하고 저장하세요. 편집 중 화면을 나가려 하면 저장하지 않은 변경을 버릴지 확인합니다. 취소하면 편집을 계속할 수 있습니다.

## 댓글 남기기

1. 업무 아래의 댓글 입력란에 내용을 적으세요.
2. 필요한 파일이 있다면 첨부하세요.
3. ‘보내기’를 누르세요.
4. 활동에 댓글이 나타나는지 확인하세요.

![업무의 변경 기록과 보낸 댓글을 확인합니다](images/task-comment.jpg)

## 사진과 파일 넣기

본문을 편집하면서 파일을 추가하면 내용과 함께 배치할 수 있습니다. 사진은 읽기 화면에서 눌러 확대할 수 있습니다. 허용 형식과 파일 크기는 업로드 화면의 안내를 따르세요.

파일이 보이지 않으면 업로드가 완료되었는지와 업무 접근 권한을 확인하세요. 댓글은 입력만 하고 닫으면 전송되지 않습니다.
