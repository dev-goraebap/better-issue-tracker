# 08. 디자인 언어: 리니어 분석 (2026-10-24)

리니어(linear.app)를 사용자 계정으로 직접 조작하며 잰 결과다. 목록·필터·표시 옵션·뷰 만들기·새 이슈 창·속성 선택·마감일·상세·칸반·타임라인·명령 메뉴·설정·뷰 목록을 열어 보았고, 수치는 브라우저 계산값(CSS px)이다. 색은 리니어의 LCH 값을 sRGB로 바꿨다(라이트 `#f9f9fa`·`#efeff0`이 리니어 공개값과 같아 변환을 확인했다). 어두운 테마는 사용자의 'Magic Blue'에서 쟀고, 중립 'Dark' 값은 리니어 변수(`--bg-base-color-dark` 등)에서 읽었다.

BIT에 옮길 기준은 4절, 기존 결정과 부딪히는 점은 5절이다.

## 1. 단순해 보이는 이유

| 원칙 | 리니어가 하는 것 |
| :--- | :--- |
| **글자 크기 네 개** | 12px(칩·버튼·보조), 13px(행·메뉴·사이드바), 15px(본문·섹션 제목), 24px(상세 제목). 굵기는 450(보통)·500(조금 굵게)·600(제목)만 쓴다. |
| **높이 다섯 개** | 24(칩·필터 조각·작은 버튼), 28(툴바 버튼·뷰 칩·사이드바 항목), 32(메뉴 항목·표시 옵션 행), 36(그룹 머리), 44(목록 행). |
| **모서리 규칙** | 누르는 것은 알약(버튼·칩·아이콘 버튼 9999px). 칸을 차지하는 것은 8px(사이드바 항목·선택 상자·카드·그룹 머리). 떠 있는 것은 12px(팝오버·메인 패널). 다이얼로그만 크게(약 20px). |
| **선 대신 면** | 테두리는 0.5px 헤어라인이고, 구분은 대부분 배경 명도 차이로 한다. 그룹 머리는 선이 아니라 한 단계 밝은 띠다. |
| **강조색 아끼기** | 인디고(라이트 `#5e6ad2`, 다크 `#575bc7`)는 주 버튼, 켠 스위치, '바뀜' 점, 오늘 표시에만 쓴다. 나머지는 회색 네 단계다. |
| **글자는 회색 네 단계** | primary(제목·값), secondary(본문), tertiary(키·날짜·라벨 글자·설명), quaternary(비활성·자리표시). |
| **아이콘은 작게** | 버튼 안 14px, 메뉴 16px. 선 굵기는 가늘고 일정하다. |
| **키보드가 먼저** | 메뉴 항목과 툴팁에 단축키가 함께 적혀 있다(필터 `F`, 새 이슈 `C`, 상태 `S`, 우선순위 숫자 `0~4`, 'G 다음 E' 같은 이동). |

| 글자 primary / secondary / tertiary / quaternary | `#1b1b1b` / `#2f2f31` / `#5c5c5e` / `#9c9d9f` | `#ffffff` / `#e4e5ed` / `#9a9aa2` / `#5e5e66` |

**그림자**
- 팝오버(라이트): `0 6px 18px rgb(0 0 0 / .02), 0 3px 9px rgb(0 0 0 / .04), 0 1px 1px rgb(0 0 0 / .04)`
- 팝오버(다크): `0 3px 8px rgb(0 0 0 / .125), 0 2px 5px rgb(0 0 0 / .125), 0 1px 1px rgb(0 0 0 / .125)`
- 다이얼로그: 4px/40px, 3px/20px, 3px/12px, 2px/8px, 1px/1px를 겹친 아주 옅은 그림자. 뒤를 검정 40%로 덮는다.
- 메인 패널: `0 3px 6px -2px rgb(0 0 0 / .02), 0 1px 1px rgb(0 0 0 / .04)`

**움직임**: 빠른 전환 0.1s, 보통 0.25s, 느린 0.35s.

## 4. BIT 적용 기준

**글꼴**: Pretendard를 유지한다. Pretendard의 라틴 글자는 Inter 기반이라 리니어와 같은 인상을 준다. 굵기 450을 '보통'으로 쓴다.

**크기**

| 토큰 | 값 |
| :--- | :--- |
| 글자 | 12 / 13 / 15 / 24 (상세 제목) |
| 높이 | 24 / 28 / 32 / 36 / 44 |
| 모서리 | 알약(누르는 것), 8(칸·카드·사이드바), 10(설정 카드), 12(팝오버·패널), 16~20(다이얼로그) |
| 테두리 | 헤어라인(0.5px, 기기 픽셀 1개) |

**부품**
- 아이콘 버튼은 28px 원이고, 바뀜·적용 중 표시는 7px 강조색 점이다.
- 칩은 24px(필터 조각·속성·라벨)과 28px(뷰 칩) 두 가지다.
- 메뉴는 맨 위가 검색 칸이고, 항목 32px, 아이콘 16px, 단축키는 오른쪽에 둔다.
- 다이얼로그는 위쪽에 띄우고, 머리는 브레드크럼이며, 테두리 없는 제목과 바닥 줄로 구성한다.

**모바일** (리니어에는 없는 부분)

| 데스크톱 | 휴대폰 |
| :--- | :--- |
| 팝오버·메뉴 | 바텀시트 (같은 내용, 행 44px) |
| 옆으로 펼치는 하위 메뉴(필터 값) | 시트 안에서 다음 단계로 밀기, 뒤로 가기 |
| 다이얼로그(새 이슈) | 전체 높이 시트. 속성 알약 줄은 가로로 스크롤 |
| 우클릭 메뉴 | 길게 눌러 여는 시트 |
| 단축키 표시·툴팁 | 숨김 |
| 뷰 칩 줄 | 가로 스크롤 칩 |
| 툴바 아이콘 28px | 터치 영역 44px (보이는 원은 28~32px) |

## 5. 기존 결정과 부딪히는 점

| 결정 | 지금 규칙 | 리니어 |
| :--- | :--- | :--- |
| **D-058** | 버튼은 알약을 쓰지 않는다. 메뉴 항목 모서리 4px, 사진은 둥근 네모. | 버튼·칩·아이콘 버튼 모두 알약, 메뉴·사이드바 항목 8px, 사진은 원 |

| **색 테마** | stone 기본에 6가지 색 테마(살구·밤바다 등) | 중립 회색과 인디고 한 가지(사용자 테마는 따로 만드는 기능) |

## 6. 적용 순서 (제안)

1. **토큰**: 색 회색 단계, 글자·높이·모서리·그림자를 `app/styles`에 정의하고 Astryx 변수에 연결한다.
2. **떠 있는 면**: 팝오버, 메뉴, 다이얼로그, 토스트, 바텀시트.
3. **툴바**: 뷰 칩 줄(D-066의 뷰), 필터 메뉴와 조각 칩 필터 줄, 표시 옵션.
4. **목록·칸반·타임라인·상세**: 행 44px, 그룹 띠, 카드, 속성 패널.
5. **새 이슈 창과 속성 선택**: 검색 칸이 있는 선택, 말로 입력하는 날짜.
6. **모바일**: 4절 표대로 바꾼다.
