# 05. UI

> **바뀜 (2026-10-26, D-091~D-094)**: 업무는 화면에서 '업무'(작업·일정 두 종류)다. 프로젝트를 펼치면 하위 메뉴 '업무'·'문서'가 있고, 워크스페이스 '문서함'은 프로젝트 폴더와 공통 폴더를 함께 보인다. 결정기록은 문서다. 아래 '문서함 / 산출물'·'결정' 절은 예전 설계다.

Kaneo를 베이스로 한다. Kaneo는 프로젝트별 업무(보드/리스트/타임라인)에 집중한 경량 도구.
BIT는 그 위에 **엔티티 3개(결정·산출물·세션)와 그 사이의 링크**를 더한다.
UI 추가분은 그 링크를 보여주는 **연결 타임라인**과 **맥락 패널**이 거의 전부.

## 워크스페이스 메뉴 (Kaneo + 추가)
- Home, Inbox, My Tasks, Members (Kaneo)
- **문서함** (신규, D-015): 폴더 트리 + 산출물. 프로젝트 라벨로 거르기

## 프로젝트 사이드 메뉴
- 보드 (Kaneo)
- 업무 (Kaneo, 확장)
- **결정** (신규)
- **산출물** (신규)
- **세션·회의** (신규)
- 타임라인 (Kaneo)

## 1. 결정 (신규)
- 목록: 상태(제안/확정/대체됨) 필터
- 상세: 무엇을 / 왜 / 기각한 대안 / 출처(세션·회의) / 파생 업무 / 영향 산출물
- 이행 진행 표시: "이행 2/3" (파생 업무 종료 수로 계산, 없으면 "해당 없음")
- "대체됨"은 대체한 결정으로 링크

## 2. 문서함 / 산출물 (신규)
- 워크스페이스 문서함: 파일 탐색기처럼 폴더 트리. 폴더·산출물 만들기, 옮기기, 프로젝트 라벨 붙이기
- 프로젝트의 "산출물" 메뉴: 그 프로젝트 라벨이 붙은 산출물만 거른 목록 (폴더 경로 표시)
- 목록은 산출물 한 줄씩. 원본·텍스트 사본을 따로 늘어놓지 않는다. 정본 종류 배지(docx / md / Git), 파생본은 버튼 (D-016)
- 일반 파일(1차): 상세에 정본·파생본 버튼, 연결된 업무·결정. "관리 문서로 전환"은 이후
- (이후) 관리 문서 상세: 개정이력표(버전 / 상태 / 개정 사유 / 변경 요약), 버전 비교, 확정하기
- 원본 다운로드 + 변환 텍스트 보기 (사람과 에이전트가 같은 화면)
- (이후) 반영 대기함

## 3. 세션·회의 (신규)
- 팀 회의록과 에이전트 세션 요약을 한 목록에 (출처 유형 필드로 구분)
- 각 기록에서 결정 추출 (버튼 또는 에이전트가 MCP로 자동 생성)
- 사용자의 사내 플랫폼 회의록 경험을 그대로 가져온다

## 4. 업무 상세 (Kaneo 화면 확장)
- 트리거 유형 배지, 결정 링크
- **연결 타임라인**: 세션 → 결정 → 문서 개정 → 커밋/MR 시간순
  (Kaneo 활동 로그·댓글 영역을 확장하는 방향)

## 5. 맥락 패널 (업무 상세 오른쪽)
- 왜(결정) / 근거 문서(버전) / 코드(브랜치·MR)
- **"에이전트용 맥락 복사"**: 업무 + 결정 + 문서 최신본 요약을 Markdown 한 덩어리로.
  MCP를 못 쓰는 환경용.

## 6. 프로젝트 홈 (흐름 E 대응)
최근 결정, 진행 중 업무, 최근 개정 문서를 한눈에. "오랜만에 돌아왔을 때" 용도.

## 1차에서 넣지 않는 것
문서 편집기, 결재 워크플로, 위키. Kaneo가 가벼워서 좋았던 이유를 지킨다.
