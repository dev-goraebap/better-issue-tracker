# 결정기록 틀

결정기록 본문은 이 세 섹션만 쓴다. 맥락과 결정은 각각 2~5문장이다. 검토한 대안은 실제로 따져 본 안이 있을 때만 쓴다. 언제 쓰고 어떻게 다루는지는 [결정기록](../playbooks/decision.md)에 있다.

```markdown
## 맥락

무엇 때문에 정해야 했는지: 드러난 문제(잰 수치가 있으면 그것), 누가 무엇을 요청했는지, 지켜야 할 제약.
이 결정이 나온 작업 업무: ORM-20 (없으면 "사용자가 대화에서 정함"처럼 나온 곳)

## 결정

무엇을 하기로 했고 어디까지 적용하는지, 예외가 있으면 그것.

## 검토한 대안

- 고르지 않은 안 (그 까닭을 짧게)
```
