# 서버

[작업별 매뉴얼 지도](../references/architecture/project-documents.md)에서 **서버 배치 / DTO·명명·형식 / 도메인 / 트랜잭션 / SQL·페이징**에 해당하는 개발 절차와 아키텍처 설계 페이지를 읽습니다. 작업 범위가 여러 영역이면 관련 행도 함께 선택합니다.

1. 로컬 매뉴얼 원본과 현재 코드·설정·검사에서 적용 계약을 확인합니다. 로컬 원본이 없으면 누락 범위와 확인한 코드 근거를 밝힙니다.
2. 관련 절차에 따라 변경하고 매뉴얼의 검증 기준으로 검사합니다. 상세 규칙·코드 예를 이 플레이북에 다시 유지하지 않습니다.
3. 변경 영향에 맞는 매뉴얼을 공통 `better-issue-tracker`의 유지관리 절차로 갱신합니다. 사용자 동작 변경은 [실제 검증](verify.md)을 수행합니다.
