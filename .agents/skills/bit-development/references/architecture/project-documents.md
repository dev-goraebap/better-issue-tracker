# 프로젝트 지식의 저장소 원본

BIT는 `docs/manuals/`를 매뉴얼 콘텐츠 원본으로 사용한다. 게시 대상과 섹션/페이지 key는 `docs/manuals/publication.json`에 있다. 작업 전에 아래에서 필요한 로컬 원본만 읽고 코드/검사와 대조한다. MCP는 업무·개선 의견·게시 충돌 확인에 사용하며 개발 규칙을 읽기 위한 필수 경로가 아니다.

게시와 블록 호환성은 공통 better-issue-tracker의 `references/manual-publication.md`를 따른다. 현재 원본은 운영 최신 본문을 보존해 가져온 것이며 전체 내용을 현 코드와 재검수 완료했다는 뜻은 아니다. 이관 참고 표준의 적용 한계는 본문을 확인한다.
